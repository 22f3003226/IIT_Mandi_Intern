# Sample outputs

This folder holds sample `TeacherKnowledgePackage.json` files generated by
running the full pipeline (upload -> plan -> publish) end to end on real
documents.

Not included yet: generating a real sample requires an OpenRouter API key
and an actual LLM run, so these can't be faked. To produce one:

1. Set `OPENROUTER_API_KEY` in `.env` (see the main README).
2. Start the backend: `uv run uvicorn app.main:app --reload`.
3. Upload a document via `POST /documents`, then chain through
   `POST /jobs/{id}/plan` and `POST /jobs/{plan_job_id}/publish` (or just
   use the frontend wizard at `http://localhost:5173`).
4. Copy the completed publish job's `TeacherKnowledgePackage.json` from
   `storage/files/{publish_job_id}/` into this folder.

Aim for at least 2 samples from different subjects (e.g. one STEM, one
humanities) per the assignment brief.
